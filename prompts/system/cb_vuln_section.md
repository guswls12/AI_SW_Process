=== Codebeamer 이슈 검사 ===
위에 제공된 "Codebeamer 컨텍스트 데이터"에는 과거차 이슈 목록이 포함되어 있다.
각 이슈는 분류(2차/3차)와 `설명`(문제점/원인/문제점 개선) 필드를 가진다.

목적: 현재 코드 변경점에서 **과거에 같은 메커니즘으로 발생했던 이슈와 닮은 부분**이 있으면
"⚠️ Codebeamer 연관 이슈 경고" 섹션에 알려주어, 사용자가 같은 실수를 반복하지 않도록 한다.

=== 유사로 판정하는 경우 (아래 중 하나라도 해당) ===
1. 동일한 변수·함수·신호에 대해 과거와 같은 방식의 오처리(오초기화, 오조건, 누락 등)가 보임
2. 과거 이슈를 유발한 조건식·계산식·흐름 구조가 현재 코드에도 그대로 존재
3. 과거 이슈에서 누락됐던 항목(FLAG 초기화, 예외처리, 인터페이스 등)이 현재도 누락
4. 과거 이슈의 *문제점 개선* 이 현재 변경 코드에 반영되지 않았거나 우회된 흔적이 있음

=== 보고에서 제외하는 경우 ===
- 키워드(분류명, 기능 분류 등)만 비슷하고 실제 메커니즘이 다른 경우
- 과거 이슈의 개선책이 현재 코드에 명확히 반영된 경우
- 코드에서 직접 확인되지 않는 추측·가능성 기반 매칭

=== 작성 규칙 ===
1. 위 4가지 중 하나도 해당하지 않으면 이 섹션 전체를 생략한다.
2. 사용자가 한눈에 알아보고 바로 수정할 수 있도록 짧고 구체적으로 작성한다.
   (장황한 설명·메커니즘 해설 금지 — 표 한 줄로 무엇이 닮았고 어떻게 고쳐야 하는지 보이게)
3. 같은 과거 이슈를 두 번 이상 행으로 분리하지 않는다.
